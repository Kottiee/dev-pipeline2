# トラブル対応

CLIのコマンド体系と正常な状態遷移は[CLI操作ガイド](cli-operations.md)、Webサービス自体の起動失敗は[launchd常時起動ガイド](launchd.md)も参照してください。

## CLIで実行できない

### `cannot run agent while state is ...` と表示される

`dev-pipeline status <案件ID>` で現在状態を確認します。

- `AWAITING_HUMAN_CHECK`: `human-check` で承認または修正依頼を入力する
- `COMPLETED`: 全フェーズが完了しているため、追加のRunは開始できない
- `PHASE_REVIEWING`: `run --until-ready` で再開するか、診断目的で `review` を実行する

### `devpipeline-tests.json is missing` と表示される

成果物リポジトリ直下の `devpipeline-tests.json` がないか、有効な `command` がありません。Agentにテストとマニフェストを作成させるか、`--check '名前=コマンド'` を指定して再実行します。

### `この案件は別のプロセスで実行中です` と表示される

同じ案件の変更処理が既に動いています。別ターミナル、Web UI、常時起動サービスのジョブを確認し、完了または停止するまで待ちます。`status` と `show` は処理中でも実行できます。

### Agentの認証・実行エラーで止まる

`<work-dir>/<案件ID>/agent-logs/` の最新ログを確認し、利用中のAgent CLIを単体で実行できるか確認します。認証やPATHを直した後、同じ `--work-dir`、案件ID、外部の `--repo` を指定して `run --until-ready` で再開します。途中までのファイル変更は自動では戻りません。

### 別の案件やリポジトリが表示される

相対パスの基準となる起動ディレクトリが前回と異なる可能性があります。`--work-dir` と外部の `--repo` を絶対パスで指定し、`state.json` と成果物の場所を確認してください。

## Web UIで操作できない

まず案件一覧を再読み込みし、同じ表示が続くか確認してください。承認や修正依頼を連続して押さないでください。同じ操作の重複は防止されますが、最新状態を確認してから対応するのが安全です。

### 「接続エラー」と表示される

1. スマートフォンの通信状態を確認します。
2. Tailscaleが接続済みか確認します。
3. 管理者から案内されたURLを開いているか確認します。
4. 改善しない場合は、実行用PCとサービスが起動しているか管理者へ確認します。

### 通知が届かない

案件一覧を開き、実際の状態を確認します。そのうえで次を確認してください。

- 端末でこのアプリの通知が許可されている
- 集中モードや省電力設定で通知が抑止されていない
- iPhoneではSafariからホーム画面へ追加したアイコンで開いている
- 「通知設定」のテスト通知を受信できる

通知は補助機能です。届かなかったことによって案件の処理や承認待ち状態が失われることはありません。

### 「画面を更新してから操作してください」と表示される

表示後に案件の状態が変わっています。画面を再読み込みし、最新のテスト結果とレビュー結果を確認してから、もう一度判断してください。

### 「この案件またはリポジトリは既に実行中です」と表示される

同じ案件、または同じ成果物に対する別の処理が動いています。現在の処理が終わるまで待ちます。長時間変わらない場合は管理者へ連絡してください。

### 「実行エラー」または「中断」と表示される

案件の「実行ログ」を開き、最後に表示された内容を管理者へ伝えます。接続やAIサービスの認証を管理者が復旧した後、「実行を開始・再開」を選びます。

再実行しても、それまでに承認したフェーズは失われません。未完了のフェーズから続行します。

### 停止したのにファイル変更が残っている

「実行を停止」は処理を止める操作で、それまでの作業を取り消す操作ではありません。変更を戻す必要がある場合は、自分で再実行せず管理者へ連絡してください。

### 成果物をスマートフォンで確認できない

この画面は進捗、テスト、レビュー、承認を扱うもので、成果物の画面やファイルは配信しません。成果物の確認場所や起動方法を管理者へ確認してください。

### 管理者が確認する項目

- 実行用PCが起動し、スリープしていないか
- `dev-pipeline-web` が起動しているか
- Tailscale Serveとアクセス制御が有効か
- AIエージェントの認証が有効か
- 作業保存先と成果物の保存先へアクセスできるか
- 実行ログにテスト、認証、権限、容量不足などのエラーがないか

サービスを再起動すると、実行中だった案件は「中断」と表示されます。状態を確認してから、利用者に再開を案内してください。
